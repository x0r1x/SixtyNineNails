# SixtyNineNails

Салон маникюра — тёмный воздушный минималистичный сайт.

Стек: Next.js App Router + TypeScript + Tailwind CSS.

## Страницы

- `/` — Hero
- `/uslugi` — прайс-лист
- `/mastera` — профили мастеров
- `/zapis` — запись онлайн (JSON persistence в `data/bookings.json`)

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```
